# Driving audio worksheet

Use this to judge the sound while actually driving. The question that matters most is whether the engine and tires respond naturally to what the car is doing.

Everything below is blank until a person has driven it. Automated results are recorded separately, in the pull request and in `artifacts/gameplay-audio-report.json`, and they don't answer these questions.

To set up, follow [Listen to it locally](GAMEPLAY-AUDIO.md#listen-to-it-locally). Before you start, hover over the Sound button and check that it says **Coyote Hybrid (recorded)**.

## Driving

| # | Do this | Listen for | Result | Notes |
|---|---|---|---|---|
| 1 | Press Enter and wait on the grid | Idle starts by itself. It sounds like a plausible idle and isn't annoying after 20 seconds | | |
| 2 | Accelerate from a standstill | RPM rises immediately and climbs, with audible but unobtrusive upshifts into each gear and no jumps | | |
| 3 | Hold speed down the long straight | The engine holds a convincing elevated note. No oscillation, obvious loop, beating or pumping | | |
| 4 | Lift off at speed | Intensity falls first, then pitch settles naturally | | |
| 5 | Corner normally, without sliding | Subtle scrub at most. Straight-line driving makes no tire noise | | |
| 6 | Enter a drift with a handbrake tap | Tires come in as the tail steps out, not on the key press | | |
| 7 | Hold a power drift | Engine stays aggressive with no pitch sag. A sustained squeal that's clearly different from cornering | | |
| 8 | Recover traction | Squeal fades smoothly and the engine settles with no abrupt cut | | |
| 9 | Spin out | The sound fits what the car is doing, with nothing stuck or absurd | | |
| 10 | Drive onto the grass | Tires are softer and less sharp than on the road | | |
| 11 | Brake hard to a stop | Pitch falls with speed, and tires go silent once stopped | | |
| 12 | Reverse | A plausible low-to-moderate engine note | | |
